📲 Pasang di Homescreen HP ini

Pasang PAP Berdua jadi aplikasi di homescreen — tanpa Play Store / App Store.

Di iPhone: tap tombol Bagikan (kotak dengan panah ke atas) di Safari → pilih “Tambah ke Layar Utama” → Tambah. Selesai, ikon 💌 PAP Berdua muncul di homescreen.

Di Android: kalau tombol pasang belum muncul, buka menu Chrome ⋮ → “Instal aplikasi” / “Tambahkan ke Layar Utama”.

⚠️ Fitur PAP belum aktif di database. Jalankan dulu SQL pap-berdua.sql di Supabase (SQL Editor → tempel → Run), lalu muat ulang halaman ini.
